# 沙发上的疲惫 Brian

本宠物由 AI 辅助制作，保留 Brian 坐在紫色沙发上的疲惫形象。九种客户端状态分别使用发呆呼吸、向右张望、向左张望、挥手、伸懒腰、惊讶恢复、打哈欠、操作遥控器和思考。

运行和跳跃状态采用坐姿动作，主体始终留在沙发上。36 张关键姿态按客户端所需帧数播放，其中端点有短暂停顿；不是视频级连续动画。

安装时将 `pet.json`、`spritesheet.png` 放入 `%USERPROFILE%\.codex\pets\tired-brian\`。在 Codex 设置中选择「沙发上的疲惫 Brian」。已运行的客户端若缓存旧图，可重启后重新选择。

打开 `preview.html` 可以同时预览九种动作，拖动上方主体检查完整性。`keyframes-review.jpg` 展示 36 张关键姿态；各状态 GIF 展示实际播放帧。`validation.json` 记录每格主体边界，所有格子的四周至少有 10 像素透明留白。

制作工具为 OpenAI 内置 image_gen。关键姿态分成三组生成，再提取实际主体区域并打包成 1536 × 1872、8 列 × 9 行透明 PNG。原始角色设计来自《恶搞之家》，本项目是非官方爱好者作品，AI 制作说明不代表角色原创。
